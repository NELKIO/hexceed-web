# Hexlume

Логическая головоломка на шестиугольниках прямо в браузере: зажги все огоньки, ни разу не угадывая.
Каждое поле решается чистой логикой — это проверяет встроенный решатель.

**Играть:** https://nelkio.github.io/hexceed-web/

- Светлая тема по умолчанию (тёмная — в настройках), телефон и ПК, жесты и клавиатура.
- **Кампания:** 14 миров, 168 уровней. Каждая новая механика объясняется короткой карточкой при первой встрече.
- **Задача дня** — одна на всех, со счётчиком серии дней.
- **Бесконечный режим** — генератор полей четырёх уровней сложности.
- **Вдвоём** — совместная игра на одном поле или гонка на одинаковых полях по ссылке. Работает без своего сервера: WebRTC через Trystero/Nostr, при неудаче — зашифрованный ретранслятор.
- **Синхронизация устройств** по ключу: прогресс складывается между телефоном и компьютером.
- **Подсказка** не просто показывает ход, а объясняет, какие подсказки на поле его доказывают.

## Как играть

Нажатие — «здесь пусто»: клетка откроется и покажет подсказку. Долгое нажатие, правый клик или режим «Огонёк» — «здесь огонёк».
Ошибка не заканчивает игру, но влияет на звёзды. Счётчик огоньков наверху — тоже подсказка.

## Механики

| | |
|---|---|
| Число | огоньки среди 6 соседей |
| Туман | видны только клетки, о которых что-то известно; поле раскрывается от стартовой клетки |
| Стены, пустоты | стена разрывает соседство и лучи; пустоты лучи перепрыгивают |
| Луч | огоньки по прямой до стены |
| Круг, кольцо, бублик | огоньки на расстоянии 1–2, ровно 2, 2–3 |
| Конус, треугольник | клин из 9 клеток от угла; дальняя часть клина |
| Точка, вихрь | одна клетка через одну; обход вокруг соседней клетки |
| Замок | откроется сам, когда зажжено N огоньков |
| Яркий огонёк | зажжённый огонёк с подсказкой |
| Вращение, переключатель | клетки поворачиваются вместе со стенами и стрелками или меняют тип подсказки |
| Большие соты, порталы | клетка из нескольких шестиугольников; проход через пустоту |
| Остров, цепь | огоньки в области за стенами; огоньки в касающихся группах |
| Вместе / врозь | `{n}` — огоньки идут подряд, `-n-` — нет |
| Глаз | сколько клеток видно по 6 прямым до первого огонька или стены |
| Чёт / нечет | только чётность числа соседних огоньков |
| Нить, зона | «=» / «≠» между двумя клетками; пунктирная область со счётом |

Точная семантика — в [docs/MECHANICS.md](docs/MECHANICS.md), архитектура — в [docs/DESIGN.md](docs/DESIGN.md).

## Разработка

```bash
npm ci
npm run dev        # локально
npm test           # правила, решатель, генератор, кампания, сеть
npm run build      # сборка в dist/
npx vite-node scripts/build-levels.ts   # пересобрать кампанию (детерминированно)
```

Стек: Vite, Preact, TypeScript. Звуки синтезируются через WebAudio, графика — SVG.
Деплой на GitHub Pages через Actions при пуше в `main`.

Оригинальный проект в жанре «гексагонального сапёра». Весь код, уровни, графика и звук свои.
