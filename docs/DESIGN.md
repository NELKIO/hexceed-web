# Hexlume — design

Original hexagonal logic puzzle for the browser (GitHub Pages), in the "hex minesweeper" genre.
Clean-room: all code, levels, graphics and sounds are original. Repo: `NELKIO/hexceed-web`,
site: `https://nelkio.github.io/hexceed-web/`.

The early puzzles should be approachable; later worlds should reward careful deduction.
Use **light «Утро» by default** (dark «Ночь» is optional; see `docs/STYLE.md`), gentle onboarding,
no game over in the default mode, and optional hints that explain *why*.

## Theme

«Огоньки»: the hidden object is a warm light. Marking a hex lights it from inside (amber glow +
soft halo onto the neighbours); the whole board glows in a wave on a win. All theme art lives in
`src/ui/art/Piece.tsx` (board glyph, halo, UI icon, logo) and the `--glow-*` / `--lit-*` tokens, so
another theme only touches those. Internal identifiers keep the old `gem` name.

## Core loop

The board is a set of hexes. Every hidden hex is either a **light** («огонёк», the "mine") or **empty**.
- Tap / left click: "this hex is empty" → it opens and shows its clue.
- Long-press / right click (or the mode switch in the bottom bar): "this is a light" → it is marked.
- A wrong guess is a **mistake**: the hex does not change, the board shakes, a soft thud plays.
  No game over. Stars: 3 (clean), 2 (≤2 mistakes+hints), 1.
- The level is done when every hex is opened or marked. Every level is solvable by pure logic
  (verified by the solver), no guessing ever needed.
- The light counter (remaining lights) is always visible and is itself a clue.

## Mechanics (exact semantics in `src/core/rules.ts`, player wording in `docs/MECHANICS.md`)

| id | name (ru) | what it means |
|----|-----------|---------------|
| basic | Число | lights among the 6 neighbours (not through walls) |
| counter | Счётчик | remaining lights on the whole board |
| availability (`fog` in level data) | Доступные клетки | the entire map is drawn; clues and static zones make hidden cells playable |
| walls | Стены | a thick edge blocks neighbours and rays |
| gaps | Пустоты | missing hexes and gaps between islands; rays can cross them |
| line, multiline | Луч | lights along one or several straight rays, stopped by walls |
| radius, ring, donut | Круг, кольцо, бублик | lights at distances 1–2, exactly 2, or 2–3 |
| cone, triangle | Конус, треугольник | lights in a wedge or a separate six-position angular area |
| dot | Точка | lights at the indicated positions two steps away |
| lock | Замок | known-empty hex that opens by itself after N lights are marked |
| rotate | Вращение | cells can rotate, moving their walls and clue directions |
| zone | Зона | dashed outline around several hexes with the light count inside |

Legacy mechanics remain readable in existing workshop links, but are not generated for new puzzles.

## Structure

```
src/
  core/        pure logic, unit-tested (vitest)
    hex.ts       geometry (flat-top axial)
    types.ts     Level format
    rules.ts     Board + Constraint semantics + exact partial feasibility
    game.ts      game state, actions, locks, chord, stars
    solver.ts    human-style logical solver: next deduction + explanation + difficulty rating
    generator.ts seeded level generator (shapes, walls, gaps, clue mix, minimisation)
    rng.ts       seeded PRNG
  levels/      campaign (generated by scripts/build-levels.ts, committed JSON) + world metadata
  ui/          Preact screens, SVG board, animations
  audio/       WebAudio-synthesised sounds (no audio files)
  net/         online co-op / race via WebRTC (Trystero over Nostr, no own server)
  i18n/        ru (default) / en
  storage.ts   localStorage progress + settings
```

## Modes

1. **Campaign** — worlds of ~12–16 levels; each world introduces one mechanic with a short
   explainer card the first time it appears, then mixes it with the previous ones.
   Difficulty rises inside a world and across worlds; the last world levels are hard.
2. **Daily puzzle** — one date-seeded puzzle for everyone (generated in-browser, deterministic).
3. **Endless** — generator with difficulty (easy / medium / hard / expert) and mechanic set.
4. **Together (online co-op)** — two players solve the same board live (room link / code);
   you see the partner's cursor and moves. **Race** — same puzzle, see the opponent's progress.

## UX principles

- Minimal chrome: board fills the screen; top bar = back, level name, light counter;
  bottom = mode switch (open / light), hint, menu. Everything else in sheets.
- Hold a revealed clue → its covered hexes highlight. Tap a clue → pin highlight. Finished clues dim.
- Double-tap a satisfied clue → chord.
- Hint: highlights the clues that prove the next move and says it in words.
- Smooth animations: flip-open, light-up glow + halo, cascade waves, level-complete bloom.
- Phone (portrait, one hand) and desktop (mouse + keyboard) both first-class.
