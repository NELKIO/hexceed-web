# План продолжения

## Текущая кампания (волна 7, `GEN_VERSION = '7.0'`)

- 132 уровня в 11 мирах. Среди обычных уровней миров 2–11 у 73 из 107 поле состоит из нескольких раздельных островов.
- Острова разделены пустыми гексами. На второй остров можно выйти через дальнюю подсказку или начать с его собственной открытой клетки.
- Все клетки и стены рисуются с начала уровня. Для больших карт сначала показывается общий план; масштаб можно увеличить жестом или колесом.
- «Тишина» и остальные исключённые механики не генерируются. Сложность создают плотность, геометрия и пересечения подсказок; последний мир имеет рейтинги 6–9.
- Звёзды и разблокировки сохранены по номерам уровней, а раскладка незаконченной партии сбрасывается, если хеш поля изменился. Старую тёмную тему без отметки о явном выборе невозможно отличить от прежней темы по умолчанию; при обновлении она становится светлой. Режим «Как в системе» сохраняется.

- **Узкие места.** Проход после минимизации: в слишком длинных отрезках лёгких ходов ослабляется
  подсказка (Тишина или кристалл вместо числа, затем подправка кристаллов на границе) — так, чтобы
  фронт там двигался парой подсказок или неглубоким шагом из трёх.
  `GenOptions.maxTrivialRun`: 25, в финалах миров 22. В рейтинге парный шаг теперь весит вдвое.
- **«Тишина»** теперь вводится в мире 1: урок w01-09. w01-01..08 — только числа.
  В мирах 1–2 «Тишины» ≤ 8 %, дальше ≤ 11 %, без скоплений.
- **Человеческая решаемость в клетках** (`ahaCells`, `hardRun`, `deepCells`):
  - миры 1–3: 0 трудных клеток;
  - миры 4–8: ≤ 4, подряд ≤ 3;
  - миры 9–13: ≤ 7, подряд ≤ 3;
  - мир 14: ≤ 14, перебор ≤ 4 клеток, подряд ≤ 3.
- **Порядок уровней:** внутри мира уровни расставлены по плановой пиле. Финал мира не ниже
  предыдущего уровня; в финалах миров 3–14 трудные шаги распределены по решению (тест: отрезок ≤ 30).
- **Размеры:** w1 ≤ 37 клеток, w2 ≤ 60, w3 ≤ 80; ширина ≤ 7 / 9 / 11 столбцов; острова не дальше одного пустого гекса.

## Открытые идеи

- Миры 1–2: в каскадах из одних чисел (туман, один стартовый ноль) парных ходов не возникает.
  Проверено перебором: после удаления любой подсказки нет ни одной парной дедукции, состояние неоднозначно.
  Финалы w01-12 / w02-12 — сплошной лёгкий отрезок (30 / 43 клетки). Варианты: второй старт на
  больших досках мира 2 или зоны/нити как «подсказки-мостики».
- Миры 9–13 в среднем 5,4 (цель 5,5–6,5); финал мира 10 — тривиальный отрезок 29.
- Сложный бесконечный: 2 из 30 сидов дают 5 (среднее 6,1).
- Новичковый прогон миров 1–3 на телефоне 390×844 (камера, размеры клеток); деплой.
